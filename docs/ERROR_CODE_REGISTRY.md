# Implemented structured diagnostic codes

| Component | Codes |
| --- | --- |
| Configuration | `CONFIG_VALIDATION_FAILED` |
| Detection | `YOLO_MODEL_LOAD_FAILED`, `YOLO_INFERENCE_FAILED`, `YOLO_BATCH_INFERENCE_FAILED`, `DETECTION_OUTPUT_INVALID` |
| Tracking and identity | `TRACKER_UPDATE_FAILED`, `TRACKER_OUTPUT_INVALID`, `REID_MODEL_LOAD_FAILED` |
| Plates | `PLATE_CROP_INVALID`, `ALPR_MODEL_LOAD_FAILED`, `ALPR_INFERENCE_FAILED` |
| Vehicle attributes | `VEHICLE_ATTRIBUTE_FAILED` |
| Geometry | `SLOT_GEOMETRY_INVALID` |
| Capture and video | `VIDEO_SOURCE_NOT_FOUND`, `VIDEO_SOURCE_OPEN_FAILED`, `VIDEO_FIRST_FRAME_UNAVAILABLE`, `VIDEO_FRAME_READ_FAILED`, `VIDEO_FRAME_INVALID`, `VIDEO_TIMESTAMP_OUT_OF_ORDER`, `CAMERA_STREAM_STALLED`, `VIDEO_OUTPUT_FRAME_FAILED`, `NO_FRAMES_PROCESSED` |
| Multicamera | `CAMERA_STARTUP_TIMEOUT`, `CAMERA_PIPELINE_INIT_FAILED`, `MULTICAMERA_NO_FRAMES_PROCESSED`, `MULTICAMERA_NO_CAMERAS_INITIALIZED`, `MULTICAMERA_NO_USABLE_CAMERA` |
| Events and outbox | `EVENT_VALIDATION_FAILED`, `OUTBOX_PERSIST_FAILED` |
| Reporting | `REPORT_GENERATION_FAILED`, `SNAPSHOT_WRITE_FAILED` |
| API | `API_INVALID_REQUEST`, `API_ROUTE_NOT_FOUND`, `API_JOB_ACTIVE`, `API_UPLOAD_TOO_LARGE`, `API_UNSUPPORTED_VIDEO_FORMAT`, `API_STORAGE_FAILED`, `API_FEATURE_UNAVAILABLE`, `API_REQUEST_FAILED`, `API_VALIDATION`, `API_INTERNAL`, `API_JOB_FAILED`, `API_OUTPUT_UNAVAILABLE`, `API_OUTPUT_PENDING` |

See [error handling](ERROR_HANDLING.md) for fallback actions and result semantics. Existing component logs also contain text codes for operations outside the structured boundaries.
