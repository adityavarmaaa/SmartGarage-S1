# Archive verification method

The final ZIP preserves code and previous evidence from the checksum-verified release, adds the production handover assets, and excludes caches, build artifacts, virtual environments, temporary databases, archive backups, deployment secrets and unrelated operational media. Media is limited to synthetic output, bounded full-detail historical probes and the requested quality comparison. Some historical imagery retains vehicle identifiers and is intended for authorized production-team review. Verify the external ZIP checksum before extraction. The packaged release manifest and inventory record member SHA-256 values, excluding their own circular references. The external packaging verification report records the actual CRC, member checks and fresh-extraction execution results.
